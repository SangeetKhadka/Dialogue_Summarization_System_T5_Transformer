# Project Description
This is a dialogue summarization project developed using T5 Transformer. The T5 Transformer is finetuned on samsum data. 

# Project Structure
1. data/samsum-train.csv: Training Data
2. data/samsum-validation.csv: Validataion Data
3. data/samsum-test.csv: Testing Data
4. notebooks: Data Cleaning and Model Building 
5. app/app.py: FastAPI Code
6. app/index.html: Front End Template

# Setup
1. Create venv: "python -m venv myenv"
2. Activate it and run "pip install -r requirements.txt"
